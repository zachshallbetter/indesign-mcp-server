# Initial Epics Template

Do not create all of these automatically. Instantiate only the epics required by observed project state.

## Epic 0 — Operating substrate

Prove:

```text
identity
formal source pins
authority
context compilation
work graph
provider binding
one reversible cycle
blocker reselection
```

Exit: operating substrate `Tested`.

## Epic 1 — Canonical domain definition

Only if the project lacks a stable domain model/PRD/schema.

Output should define the smallest sufficient concepts and boundaries.

## Epic 2 — Existing-state audit

For existing projects, compare canonical contract against implementation/live state. Convert fillable gaps into bounded issues. Retain absent/unknown/contradictory state.

## Epic 3 — First end-to-end value path

Implement the narrowest path that proves the project's originating intent.

## Epic 4 — Qualification / evidence

Close only the claims that matter to the first value path.

## Epic 5 — Operational hardening

Add production/service autonomy only after bounded evidence supports it.

## Domain overlays

Profiles may propose additional epics, but base project governance never assumes commercialization, UI, physics, research or deployment is required.
