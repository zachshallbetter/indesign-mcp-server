# Agent Capabilities

Prefer a small execution-role set. Domain specialization belongs in skills, work packets and profiles rather than permanent agent identities.

## Coordinator

Maintains live project state and lawful Ready frontier.

Does not invent authority, scope or evidence.

## Worker

Executes one bounded work item in an isolated surface.

May use domain skills supplied by the issue context.

## Evaluator

Independently evaluates a frozen candidate against declared acceptance/evidence obligations. No candidate edits during the evaluation pass.

## Reconciler

Read-only reconstruction of current repository/provider/work/evidence state.

## Context Compiler

Produces deterministic project corpus and bounded work packets. Never changes canonical meaning.

## Why this is small

“Asset scout,” “market researcher,” “pilot designer,” “OCR reviewer,” “UI implementer,” etc. are task capabilities, not authorities.

Creating a named agent for every activity increases duplicated doctrine and routing burden. Specialize the work; keep the execution roles stable.
