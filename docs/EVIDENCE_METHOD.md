# Evidence Method

Evidence records what was actually established against an identifiable artifact, environment, revision, or participant condition.

Evidence does not acquire authority merely by existing.

## Core outcomes

Use the weakest accurate disposition:

```text
observed
reproduced
not_reexecuted
contradicted
inconclusive
human_required
```

`not_reexecuted` is not refutation.
`contradicted` must preserve the conflicting observation.
`human_required` cannot be closed synthetically by an agent.

## Required provenance

Record where relevant:

```text
claim or work item
artifact/revision
environment
procedure/commands
result
negative paths
limitations
producer/evaluator
context or repository identity
```

Do not manufacture precision the environment does not expose.

## Maturity

Never collapse:

```text
Documented
Implemented
Tested
Empirically Validated
```

Nor:

```text
candidate verified
landed
landed-state verified
evidence closed
promoted
```

Evidence strength and promotion authority are separate dimensions.
